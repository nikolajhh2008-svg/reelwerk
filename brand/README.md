# brand/ – your project, filled in by the AI

This folder is empty on purpose. On the first run the AI analyses your project ([blueprint/00-analyze.md](../blueprint/00-analyze.md)) and fills these files; you confirm them once ([01-strategy.md](../blueprint/01-strategy.md)).

| File | What |
|---|---|
| `project.md` | what the product is, who it is for, two-second moments, how it can appear on screen, **which kinds of video fit (inform / entertain / show) and why** |
| `strategy.md` | the one viewer, goal, bullseye, buckets with shares, formats, weekly count |
| `voice.md` | who you are, how you sound, positions, off-limits, proof, the ask |
| `rules.md` | words never to use, claims never to make, disclosures, data never to show |
| `assets.md` | every usable image, recording and character pose with its path and what it is good for |
| `theme.json` | colours and fonts (maps onto Onda's brand slots) |
| `assets/` | images, recordings, character poses, logo |
| `fonts/` | font files (`.woff2`/`.ttf`) – local, so renders are deterministic |
