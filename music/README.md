# music/ – your music pool (optional, recommended)

Human-made tracks you are allowed to use, edit and publish commercially – e.g. [Incompetech](https://incompetech.com) (Kevin MacLeod, CC BY 4.0, credit required) or [Mixkit](https://mixkit.co/license/#musicFree) (no credit, no bulk downloads by script). Put the audio files here and list every track in `music/QUELLEN.md` (or `SOURCES.md`): file · title · artist · source URL · licence · credit line (or "none") · mood · download date.

When this folder has tracks, step 4 (`blueprint/04-script.md`, 4.6) picks from it before generating music. Audio files are not committed (see `.gitignore`); the list is.
